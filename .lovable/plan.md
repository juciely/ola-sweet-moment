# Plano de Refatoração UI/UX - Elite+ Performance

Ajustar a interface para uma estética mais premium e equilibrada, focando em usabilidade mobile, tipografia moderna e integração de recursos visuais (imagens de stock).

## 1. Tipografia e Headlines
- Substituir a headline atual por uma tipografia mais legível e moderna para web (Mantendo Bebas Neue apenas para detalhes ou trocando por algo mais "display premium").
- Ajustar tamanhos de fonte no mobile para evitar quebras estranhas.

## 2. Botões e Espaçamento
- Reduzir o padding e tamanho geral dos botões para um visual mais elegante.
- Aumentar o padding lateral (container) em todas as seções, especialmente no mobile (de 24px para 32px ou usando margens dinâmicas).

## 3. Identidade Visual e Imagens
- Inserir imagens de stock de alta qualidade (academia premium, luz dramática, foco em performance) em locais estratégicos:
  - Hero (fundo mais nítido ou composição lateral).
  - Seção Storytelling.
  - Novos backgrounds para seções de planos.

## 4. Otimização Mobile
- Garantir que nenhum elemento encoste nas bordas da tela.
- Ajustar o grid de planos para melhor empilhamento.
- Refinar o formulário de captura para ocupar melhor a tela mobile.

## Detalhes Técnicos
- Utilizar Unsplash para imagens de placeholder de alta qualidade.
- Ajustar CSS global para margens laterais consistentes.
- Revisar componentes de Botão para escalas menores.
